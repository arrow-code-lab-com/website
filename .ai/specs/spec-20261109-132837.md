### 1-3. 実機で確かめた前提

- `src/layouts/BaseLayout.astro` は og:type・og:site_name・og:title・og:description・og:url・og:locale を出しているが、og:image と twitter:card は無い
- title は `title` を渡すと「{title} | Arrow Code Lab」、渡さないと「Arrow Code Lab」。トップ（`HomePage.astro`・`EnHomePage.astro`）は渡していない
- description の既定は `src/i18n/ui.ts` の `site.description`。日本語は「アプリケーションの開発・公開、アプリ開発のご依頼、AI活用のご相談を承る個人事業です」と自社アプリが先に来る
- ヘッダー（`src/components/Header.astro`）は、幅 40rem 以下でサービス・開発事例を隠し、お問い合わせ（`#contact`）と言語切り替えを文字で出す。英語ページではサービスを出さない
- Hero の主ボタンは Google フォームを別タブで開く（`target="_blank" rel="noopener"`）
- 依存パッケージは astro と型チェック用だけ。og 画像を作る仕組みは無い
- `public/` にあるのは `CNAME` と `favicon.svg` だけ

### 1-4. 重要度

影響範囲: すべて／戦略: アドバンテージ

### 1-5. 受入の観点

- トップ（日本語・英語）を共有すると、画像とタイトルが出る（og:image が絶対 URL で、1200×630 の PNG が実際に配信される）
- アプリ詳細・ポリシーを共有しても、画像が出る（共通の画像）
- 日本語トップの title が「アプリ開発・AI活用のご相談｜Arrow Code Lab」で、事業内容が先に読める
- 下層ページの title は今の「{ページ名} | Arrow Code Lab」のまま
- スマホ幅（375px）で、ヘッダーのお問い合わせが塗りのボタンとして見え、1 行に収まる
- 日本語のヘッダーのボタンは Google フォームを別タブで開く。英語のヘッダーのボタンはページ内の Contact（メール）へ行き、Google フォームへは行かない
- 英語ページの画像・title・description に、受託・AI相談・見積もり・副業の条件の言葉が無い
- 画像にも金額・個人名・副業の条件と矛盾する約束が無い

## 3. 要件

1. og 画像（日本語用・英語用の 2 枚）
   - 1200×630 の PNG を `public/` の下に置き、元の SVG もリポジトリに置く（文言を変えるときに作り直せるように）
   - 絵柄は白地＋アクセントカラー 1 色（`#2563eb`）。左端にアクセントの帯、矢印のマーク、屋号、ドメイン
   - 日本語: 「アプリ開発・AI活用のご相談を承ります」と「業務の困りごとを、アプリとAIで解決します。」
   - 英語: 「Apps for everyday needs.」と、日本を拠点にアプリを作る個人の開発者であること。受託・相談の言葉は入れない
   - 依存パッケージを増やさない。PNG の書き出し方は実装で決め、手順を CLAUDE.md に残す
2. `BaseLayout.astro` の head
   - 全ページで、言語に合った og 画像を `og:image`（絶対 URL）・`og:image:width`・`og:image:height`・`og:image:alt` で出す
   - `twitter:card` を `summary_large_image` で出す
3. トップの title・description
   - 日本語トップの title を「アプリ開発・AI活用のご相談｜Arrow Code Lab」にする
   - 英語トップの title を「Arrow Code Lab — Apps for everyday needs」にする
   - 下層ページの title の形（「{ページ名} | Arrow Code Lab」）は変えない
   - 日本語の description を、受託と AI 相談が先に来る形に直す（Hero のリード文に揃える。言い回しは実装で決め、PR で確認する）。英語の description は変えない
4. ヘッダー（`Header.astro`）
   - お問い合わせを、塗りのボタンの見た目にする。スマホでも PC でも同じ
   - 日本語: Google フォームを別タブで開く（Hero の主ボタンと同じ `target="_blank" rel="noopener"`）
   - 英語: 今のままページ内の Contact（メール）へ。Google フォームへはつながない
   - スマホ幅（375px）で、ロゴ・ボタン・言語切り替えが 1 行に収まる。サービス・開発事例を隠すのは今のまま
5. ほかのセクション・ページの中身は変えない
6. CLAUDE.md のディレクトリ構成に og 画像の置き場所を加え、作り直す手順を書く

## 4. 選ばれた案と確認事項への回答

**案A: 全ページ共通の画像を 1 枚（日英 2 枚）用意する** を採用（その場で `AskUserQuestion` で回答）。

屋号・事業内容の一言・矢印のマークを載せた画像を日本語用と英語用の 2 枚だけ作り、全ページで使う。依存を増やさず、ビルドも変えない。

確認事項への回答:

- Q1 トップの title: **事業内容が先**（「アプリ開発・AI活用のご相談｜Arrow Code Lab」）
- Q2 ヘッダーのお問い合わせボタンの行き先: **Google フォームを直接開く**（日本語のみ。英語は Contact のメールへ）
- Q3 英語ページ: **英語用の画像と title を用意**（「Arrow Code Lab — Apps for everyday needs」）

- 案B（ページごとの画像をビルドのときに作る）: 依存 2 つと日本語フォントが増え、ビルドが重くなる。ページが少ない今は手間に見合わない
